Meet the three machines

Same underlying technology — transistors etched into silicon. Completely different bodies, because each serves a different master.

The CPU

AMD EPYC 9654 “Genoa” · 2022 · server processor

  • 96 cores / 192 threads · 12 chiplets + 1 I/O die
  • 384 MB L3 cache · 96 MB L2 · 12× DDR5
  • Socket SP5 (LGA-6096) · up to 400 W
  • ≈13B transistors (est.)

The GPU

NVIDIA H100 SXM5 “GH100” · 2022 · AI accelerator

  • 132 SMs · 16,896 CUDA cores · 528 Tensor Cores
  • 50 MB L2 · 80 GB HBM3 @ ~3 TB/s
  • NVLink 900 GB/s · 700 W · TSMC 4N
  • 80B transistors · 814 mm² die

The DPU

NVIDIA BlueField-3 · 2022 · data processing unit

  • 16× Arm Cortex-A78 · 16× DPA cores
  • 400 Gb/s networking · PCIe Gen5 ×32
  • Up to 64 GB DDR5 · 42 SPECrate2017_int
  • 22B transistors

Side-by-side: what each has, what each lacks, and why

The physical differences aren't accidents — each missing piece is a deliberate trade. Tap the level switcher above to change the depth of the whole page.

Physical componentCPU (Genoa)GPU (H100)DPU (BlueField-3)
Primary compute units ✔ 96 big out-of-order cores — few, brilliant, branchy ✔ 132 SMs / 16,896 simple cores — an army doing the same op ✔ 16 Arm A78 cores — modest, for control-plane software
Matrix / AI accelerators ✘ none dedicated — AVX-512 covers vectors; die budget goes to cache + OoO logic ✔ 528 Tensor Cores + Transformer Engine — the whole point of the chip ✘ none — 1.5 TOPS is incidental; it steers data, doesn't train on it
Packet / crypto / storage engines ✘ none — handling packets in software wastes precious general-purpose cores ✘ none — every mm² is for FLOPS; networking lives on the DPU next door ✔ the whole point — RDMA, NVMe-oF, IPsec/TLS, virtual switching in hardware
Cache hierarchy ✔ huge — 96 MB L2 + 384 MB L3 to hide memory latency for unpredictable code ✔ 50 MB L2 only, no L3 — thousands of threads hide latency; SRAM budget → more SMs ✔ small coherent caches on a mesh — control-plane code, not number-crunching
Memory system ✔ 12× DDR5 channels, DIMMs off-package — terabytes of capacity, modest bandwidth ✔ 80 GB HBM3 on-package — ~3 TB/s bandwidth, capacity capped by stack count ✔ up to 64 GB DDR5 on-card — packet buffers and OS, not datasets
Chip-to-chip interconnect ✔ Infinity Fabric + 128× PCIe Gen5 — talks to everything: RAM, GPUs, DPUs, disks ✔ NVLink 900 GB/s — GPUs gossip with GPUs at memory speed; CPU link is secondary ✔ 400 Gb/s Ethernet/InfiniBand — the DPU is the network endpoint for the server
Package style ✔ 13-chiplet MCM, socketed LGA-6096 — yield: small dies, mix-and-match, replaceable ✔ one giant monolithic die + HBM on silicon interposer — SM-to-SM bandwidth forbids chiplet hops ✔ single SoC + heatsink on a card — integration beats raw speed; it must be cheap per server
Runs an OS / apps ✔ yes — the OS lives here ✘ no — it runs kernels the CPU launches; no OS, no interrupts ✔ yes — its own Linux (DOCA) — it's an independent computer in front of the computer

Provenance & honesty notes

Chips shown: AMD EPYC 9654 “Genoa” (Zen 4, launched Nov 2022) · NVIDIA H100 SXM5 “GH100” (Hopper, announced Mar 2022) · NVIDIA BlueField-3 DPU (announced Apr 2021, shipping 2022).

Key figures verified Sep 2026: GH100 — 80B transistors, 814 mm², TSMC 4N, 144 SMs on die (132 in H100 SXM5 product), 16,896 FP32 CUDA cores, 50 MB L2, 80 GB HBM3, NVLink 900 GB/s (TechPowerUp, TechPowerUp). BlueField-3 — 22B transistors, 16× Arm Cortex-A78, 16 DPA cores, 400 Gb/s, PCIe Gen5 ×32, ≤64 GB DDR5, 42 SPECrate2017_int (NVIDIA technical blog, Tom's Hardware). EPYC Genoa — 96 cores/192 threads, 12× 5 nm CCDs + 6 nm sIOD, 384 MB L3, 12× DDR5, 128 PCIe Gen5 lanes, SP5 LGA-6096 (TechPowerUp).

Estimates, labeled as such: Genoa transistor count (≈13B — AMD never published a figure); BlueField-3 process node (7nm-class — NVIDIA undisclosed). The 3D models are stylized schematics, not to scale and not die shots.
